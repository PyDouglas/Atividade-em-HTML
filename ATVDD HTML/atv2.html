Estofador



  • Grampeador Pneumatico
  • Tesoura
  • Martelo



  1. O grampeador é utilizado para produzir qualquer objeto de estofado (ex: puff's, sapateiras, cama, etc...).
  2. A tesoura é utilizada tanto para cortar os materiais, quanto para ajustar alguns pontos na hora de cobrir a peça.
  3. O martelo é utilizado para remover pregos, abrir madeirites grampeados, etc...
